# sample-cli

[**English**](./README.md) | [中文](./README.zh-CN.md)

Print one fixed line from a single Python file.

## Overview

`sample_cli.py` is the whole program. Running it prints `sample-cli: ok`.

## Requirements

Python 3. The script imports nothing outside the standard library.

## Installation

No install step. Run it from this directory.

## Quick Start

```bash
python3 sample_cli.py
```

The command prints:

```text
sample-cli: ok
```

This output was produced by running that command in this directory.

## Usage

The script takes no arguments. It always prints the same line and exits.
