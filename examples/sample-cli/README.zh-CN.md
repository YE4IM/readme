# sample-cli

[English](./README.md) | [**中文**](./README.zh-CN.md)

用一个 Python 文件打印一行固定文字。

## 概述

`sample_cli.py` 就是全部程序。运行后打印 `sample-cli: ok`。

## 环境要求

Python 3。脚本不使用标准库以外的包。

## 安装

无需安装。在本目录运行即可。

## 快速开始

```bash
python3 sample_cli.py
```

命令输出：

```text
sample-cli: ok
```

这段输出是在本目录实际运行该命令得到的。

## 用法

脚本不接受参数。它每次都打印同一行后退出。
