## 概述

本仓库就是这套写法的来源。在这里阅读或克隆即可，无需安装。

| 文件 | 作用 |
|---|---|
| `README-AGENT-INSTRUCTIONS.md` | 给 Agent 的执行规范，不是项目介绍。 |
| `README.template.md` | 英文模板。成稿写入目标仓库的 `README.md`。 |
| `README.zh-CN.template.md` | 中文模板。成稿写入目标仓库的 `README.zh-CN.md`。 |
| `assets/` | 署名图片。 |

## 署名
